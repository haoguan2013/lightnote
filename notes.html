通用

                    

                        

                            
开机自动启动

                            
登录 Windows 后在后台启动（驻留系统托盘，不弹出窗口），点击托盘图标即可输入 PIN

                        

                        
                    

                    

                

                

                    
数据

                    

                        

                            
导入 / 打开 Markdown

                            
「选择文件夹」批量导入其中所有 .md 文件（含子文件夹）并归入「导入」分组，标题已存在的自动跳过；「打开单个文件」先读入编辑器，点保存时再选择归入哪个分组

                        

                        
                    

                    

                        

                            
监听 Markdown 目录（新增 / 删除）

                            
把一个本地目录绑定到某个分组：目录中新增 .md 文件自动建为该分组下的笔记，文件被删除则对应笔记移入回收站；文件内容被修改不会同步（只识别新增与删除）。仅在解锁期间监听，锁定即停止；绑定关系与登记表随 vault 一起加密保存

                            
未绑定任何目录

                        

                        
                    

                    

                        
                        
                        
                        
                        
                        
                    

                    

                    

                    

                        

                            
监听 SQL 目录（新增 / 删除）

                            
把一个本地目录绑定到某个 SQL 分组：目录中新增 .sql 文件自动导入为该分组下的条目，文件被删除时对应条目标记为「源文件已删除」（不自动丢弃副本）；与上面的 Markdown 监听完全独立，可分别绑定各自的目录与分组。仅在解锁期间监听，绑定关系与登记表随 vault 一起加密保存
